# Сайт городского события «Контур»

## Инструкция запуска
Зависимости не нужны. Открыть `index.html` двойным кликом или запустить локальный сервер:
```
python -m http.server 8000
```
Открыть http://localhost:8000.

## Источник тестовых данных
Событие, площадка, организации, спикеры, программа и тексты вымышлены и сгенерированы ИИ-ассистентом Claude (Anthropic). Данные лежат в `js/data.js`. Запрос к ИИ (суть): *«Придумай вымышленное городское событие по технологиям для студентов: одна дата, три зала, 12 выступлений, 6 спикеров с краткой биографией. Названия организаций и имена должны быть вымышленными, тематика связана с автоматизацией, ИИ, безопасностью, дизайном интерфейсов и защитой студенческих проектов»*.

**Обоснование:** кейс проверяет сайт, а не содержание события, поэтому реальные организаторы и спикеры не нужны. Объёма данных (12 выступлений, 3 зала, 6 спикеров) достаточно, чтобы проверить фильтры, пустые состояния, длинные заголовки и параллельные выступления в разных залах.

**Этическая и юридическая оговорка:** данные не содержат реальных персональных данных третьих лиц. Спикеры вымышлены, совпадения случайны, на странице есть соответствующая пометка. Фотографий людей нет — вместо них аватары с инициалами. Контакты используют зарезервированный домен `.example` и условный номер. Иконки и схема площадки нарисованы вручную. Тексты лицензий шрифтов лежат в `fonts/`.

## Состояния интерфейса (для проверки)
| Состояние | Как показать |
|---|---|
| Ошибки полей и сводка | Нажать «Отправить заявку» с пустой формой |
| Пустые данные | В поиске программы ввести «абвгд» |
| Ошибка загрузки программы или спикеров | Появляется при сбое загрузки данных; есть кнопка «Повторить» |
| Ошибка отправки | Открыть `index.html?demo=error`, заполнить форму и отправить |
| Успешная отправка | Заполнить форму корректно: экран «Заявка принята» с номером заявки |

Примечание: отдельного требования к описанию архитектуры обмена данными в файле для кейса 1 нет — данные формы никуда не отправляются и не сохраняются, отправка имитируется; пользовательский ввод выводится через `textContent`, включена CSP, проверка полей только клиентская.
